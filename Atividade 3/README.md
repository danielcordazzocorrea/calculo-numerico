# Atividade prática III

`Atividade_3_Raizes.ipynb` contém a resolução executada, compatível com Jupyter, VS Code e Google Colab.

## Execução local

```powershell
python -m pip install -r requirements.txt
python -m jupyterlab
```

## Arquivos

- `atividade_3.pdf`: enunciado original.
- `Atividade_3_Raizes.ipynb`: métodos, tabela, análise, testes e animações incorporadas.
- `resultados/`: GIFs, tabela CSV/HTML, gráfico e dashboard HTML.
- `resultados_atividade_3.zip`: pacote dos resultados.
- `ROTEIRO_MATHCHA.md`: síntese dos resultados para o dashboard.
- `gerar_notebook.py`: gera novamente o notebook sem as saídas.
